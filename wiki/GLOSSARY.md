# Scientific Glossary

| Term | Definition |
|---|---|
| EIG | Expected information gain about the declared parameter vector. |
| Modeled cost | Prespecified unit cost; not measured laboratory time or money. |
| Local two-target gate | Precision thresholds for the declared core-loss and magnetizing-inductance targets. |
| Matched model | Synthetic data generated within the same model family used for inference. |
| Paired seed | Shared truth, candidate noise, and state-level randomization across policies. |
| Direct contrast | Prespecified comparator-minus-EIG endpoint comparison. |
| Evidence projection | Disclosure-safe aggregate derived from a verified frozen release. |
| Paper snapshot | Immutable export pinned to evidence, wiki, claims, figures, and bibliography. |
