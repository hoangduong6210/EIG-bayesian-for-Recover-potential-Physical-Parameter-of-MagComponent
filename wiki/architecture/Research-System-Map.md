# Research System Map

```text
preregistered configuration + candidate library
    -> paired posterior states and policy trajectories
    -> reconstructed endpoints and diagnostics
    -> immutable production freeze
    -> disclosure-safe evidence projection
    -> evidence ledger -> claim registry -> manuscript snapshot
```

The same seed fixes truth, candidate-indexed outcomes, and posterior-state
randomization across policies. Aggregation cannot repair a failed state-level
validity gate.
