# Claims and evidence

This file is a compatibility entry point. Current claim wording and numerical
evidence are maintained in the research wiki so that a result has one public
semantic owner:

- [`Current-Claim-Language.md`](../wiki/claims/Current-Claim-Language.md) for
  claim scope;
- [`Claims-and-Limits.md`](../wiki/Claims-and-Limits.md) for interpretation;
- [`Evidence-Ledger.md`](../wiki/evidence/Evidence-Ledger.md) and
  [`Evidence-Sources.md`](../wiki/Evidence-Sources.md) for numerical sources;
- [`Historical-Claim-Ledger.md`](../wiki/claims/Historical-Claim-Ledger.md) for
  superseded statements.

Document-release claims are frozen beside each PDF under [`paper/`](../paper/).
They remain historical records and are not updated when the wiki changes.
