# Experiment protocol

This file is a compatibility entry point. The active magnetic-core protocol is
maintained with the research manuscript in the wiki:

- [`Sequential-Design-Method.md`](../wiki/methods/Sequential-Design-Method.md)
  defines the acquisition method and comparator endpoints;
- [`Reproducibility.md`](../wiki/REPRODUCIBILITY.md) defines seeds, evidence
  admission, and verification;
- [`Research-Workflow.md`](../wiki/operations/Research-Workflow.md) defines the
  computation-to-claim lifecycle;
- [`Scientific-Results.md`](../wiki/results/Scientific-Results.md) reports only
  completed work;
- [`Decision 0001`](../wiki/decisions/0001-gate-aligned-objective.md) records the
  next acquisition-objective study before its outcomes are generated.

Exact executable settings remain in [`configs/`](../configs/). A conference or
journal PDF pins the protocol, evidence release, and wiki revision recorded in
its snapshot metadata; it does not become the source for later experiments.
