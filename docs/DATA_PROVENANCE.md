# Data provenance

## Source

The selected measured curves come from the local snapshot of the open `materialdatabase` project under Topic 17. `data/manifest.yaml` identifies every intended input by source, material, channel, repository-relative upstream path, and SHA-256 digest.

No raw datasets are duplicated in this manuscript folder. A staging/verification step in the implementation layer may copy the selected files into a run-specific working directory only after matching the manifest. Derived files never overwrite raw inputs.

## Interpretation

- `LEA_MTB` and `MagNet` complex-permeability CSVs are treated as public measured data according to the upstream database metadata.
- `datasheet_curves/*/p_v_over_f_at_b_T.csv` are digitized/vendor datasheet curves, not new laboratory measurements by this project.
- Synthetic observations are generated by the declared forward model and are never mixed with measured-data labels.

## Required validation

Before a heavy job starts, validation must check:

1. SHA-256 matches the manifest.
2. Required columns exist and parse as finite numbers.
3. Frequency, flux density, temperature, permeability, and loss values use the expected units.
4. Duplicate rows and nonphysical values are reported.
5. Any filtering rule is configuration-controlled and recorded in provenance.

## Licensing and citation

The upstream license text remains with the source repository and must be included in any archived reproduction bundle. `data/licenses/README.md` records this project’s handling rule. Cite the upstream database/software publication or repository in the paper; a local path is not a scholarly citation.
