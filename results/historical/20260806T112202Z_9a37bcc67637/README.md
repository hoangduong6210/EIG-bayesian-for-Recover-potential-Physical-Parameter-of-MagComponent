# Historical conference evidence

This allowlisted evidence bundle supports the conference snapshot. Its numeric
summary, tables, and figures are byte-identical copies from historical release
`20260806T112202Z_9a37bcc67637`. The original release recorded Git revision
`9a37bcc67637062cc4d9f453b8ec3ec1de257d87`.

The bundle intentionally contains scientific artifacts and content hashes only.
Machine-environment records, scheduler records, logs, and absolute paths are not
part of the public evidence package.

Start with [`paper_summary.json`](tables/paper_summary.json). Its inputs and
original SHA-256 values are listed in
[`source_artifact_index.json`](lineage/source_artifact_index.json), while the
complete historical artifact inventory, including excluded diagnostic records,
is retained in
[`complete_source_artifact_index.json`](lineage/complete_source_artifact_index.json).
The
measured input-data hashes are listed in
[`input-data-sha256.txt`](lineage/input-data-sha256.txt).

Interpretation and known corrections are maintained beside the immutable PDF in
[`paper/conference_snapshot/`](../../../paper/conference_snapshot/).
